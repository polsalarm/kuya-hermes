# Kuya Hermes brand

Pointer. The canonical write-up is [docs/dsd-kuya-hermes.md](docs/dsd-kuya-hermes.md).

Kuya is a floor lead, not a generic robot. The website is night-navy with a gold action. The Hermes Desktop plugin uses the host theme and does not copy these hex values into `plugin.js`.

| Token | Value |
|-------|-------|
| Background | `#070b1d` |
| Card | `#111a3d` |
| Text | `#eef1ff` |
| Gold | `#f5b83d` |
| Danger | `#ff6b6b` |
